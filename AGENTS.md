# Working on Shiva's Exam Journal

## Every update
- Bump `<meta name="app-version" content="YYYY-MM-DD.N">` in `index.html` (today's date, build number +1) and add the matching entry at the end of `UPDATES` (short name + 1–3 bullets). The pill next to the title shows `vMM-DD.N`; tapping it opens What's new.
- Bump the cache name in `sw.js` so phones pick up the new build.
- Keep `config.js` as it is (Firebase settings).

## Before saying it's done
Run two different checks (data audit + click-through tests) and say what both were.

## Summaries
Short bullets: what changed, what was checked, what's next.
